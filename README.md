## Тема: Наслідування та поліморфізм

### Опис завдання (Варіант №12)

На основі номера залікової книжки **5108** розраховано варіант:
* **C13:** $5108 \pmod{13} = 12$ — Об'єктна модель "Ігрова кімната".

**Завдання:** 1. Реалізувати ієрархію іграшок для дитячої ігрової кімнати.
2. Забезпечити контроль бюджету кімнати та фіксовану кількість предметів.
3. Реалізувати сортування іграшок за ціною.
4. Додати можливість пошуку іграшок за заданим діапазоном вартості.
5. Обробити виключні ситуації (Exceptions) за допомогою власних класів.

## Технології та принципи
* **Inheritance (Наслідування):** Базовий абстрактний клас `Toy` та його нащадки `Car`, `Doll`, `Block`.
* **Polymorphism (Поліморфізм):** Використання масиву типу `Toy[]` для зберігання та обробки різних видів іграшок.
* **Exceptions:** Створення та обробка власного виключення `BudgetExceededException`.
* **Sorting:** Використання інтерфейсу `Comparator` для впорядкування об'єктів.

## Структура проєкту
* `src/main/java/playroom/` — Бізнес-логіка ієрархії іграшок.
* `src/main/java/lab_5/Main.java` — Головний клас, що демонструє роботу програми та обробку помилок.
* `src/test/java/playroom/` — Unit-тести для перевірки логіки кімнати та коректності створення об'єктів.
